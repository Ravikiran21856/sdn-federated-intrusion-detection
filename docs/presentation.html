01. Research Context

Problem Statement & Motivation

Slide 02 / 20
  • The Zero-Day Vulnerability Dilemma: Cyber adversaries exploit novel vulnerabilities before vendor security patches or signatures are published. Signature engines (Snort/Suricata) exhibit 0% detection on day zero.
  • Privacy & Data Governance Constraints: Cross-institutional entities (e.g., healthcare, financial networks, multi-tenant cloud) are legally prohibited (by GDPR, HIPAA, CCPA) from pooling raw flow telemetry into a central repository.
  • Bandwidth & Controller Bottleneck: Continuous streaming of multi-gigabit raw telemetry across Wide Area Networks (WAN) exhausts network bandwidth and creates single-point-of-failure controller choke points.
Research Question: How can distributed SDN domains collaboratively learn to detect unobserved zero-day exploits with line-rate mitigation without ever exposing private raw packet telemetry?

02. Literature Critique

Existing Systems vs. Core Limitations

Slide 03 / 20
  • Signature-Based Engines (Snort, Suricata):
    • Fast on historical threats, but completely blind to novel zero-day exploits and polymorphic malware.
  • Supervised Classifiers (Random Forest, SVM, DNN):
    • Suffer from target leakage and distribution shift. Require large labeled attack sets, which do not exist for zero-day exploits.
  • Standard Federated Learning (FedAvg):
    • Implicitly assumes IID (identically distributed) data. Diverges under extreme statistical heterogeneity between IoT, Enterprise, and Data Center traffic.
  • Lack of Reactive Control Plane Integration:
    • Traditional NIDS operate out-of-band and cannot dynamically push line-rate isolation rules into network switches.

03. Proposed Solution

The AEGISNET Framework

Slide 04 / 20
  • Unsupervised Zero-Day Detection: Implements a Deep β-Variational Autoencoder (β-VAE) trained strictly on baseline benign network flows. Detects zero-days via reconstruction error spikes without needing attack labels.
  • Privacy-Preserving Federated Aggregation: Implements FedProx with proximal regularization (μ = 0.01) to guarantee convergence under non-IID traffic heterogeneity.
  • Local Differential Privacy (LDP): Enforces L2 gradient clipping (C = 1.0) and calibrated Gaussian noise to provably prevent gradient reconstruction attacks.
  • Sub-Millisecond Line-Rate Mitigation: Pushes OpenFlow 1.3 OFPFC_ADD FlowMod rules (priority=65535, action=DROP) directly to Open vSwitch in 0.49 ms.

05. Mathematical Foundations

Deep β-VAE Formulation

Slide 06 / 20
  • Probabilistic Latent Mapping: Encoder qφ(z|x) maps 16-D normalized flow features into an 8-D latent Gaussian distribution &mathcal;N(μz, σz2).
  • The Reparameterization Trick:
    z = μz(x) + σz(x) ⊙ ε,    where ε ∼ &mathcal;N(0, I)
  • β-VAE Loss Objective:
    Loss = E_{q}[||x - x_hat||^2] + β • D_KL( q(z|x) || &mathcal;N(0, I) )
  • Role of β = 1.25: Imposes an information bottleneck that forces latent representations to be disentangled and independent, preventing memorization of attack noise.

06. Detection Mechanism

Zero-Day Anomaly Scoring & Adaptive τ

Slide 07 / 20
  • Reconstruction Error Metric: S(x) = (1/D) ∑ (x_j - x_hat_j)^2
  • Generative Anomaly Separation:
    • Benign Flows: Reconstruct with high fidelity → S(x) ≤ 1.0 (Low Error)
    • Novel Zero-Day Exploits: Contain unobserved topology → S(x) >> 1.93 (High Error)
  • Adaptive Three-Sigma Cutoff (τ):
    τ = μbenign_val + 3.0 • σbenign_val = 1.9325
  • Anti-Data Leakage: Threshold τ is derived strictly from normal validation data without exposing any attack flows.

07. Distributed Optimization

FedProx & Differential Privacy

Slide 08 / 20
  • Tackling Statistical Heterogeneity: Network telemetry in IoT, Enterprise, and Cloud domains is heavily Non-IID. Standard FedAvg causes local drift and divergence.
  • FedProx Proximal Objective:
    min_w h_k(w; w^t) = F_k(w) + (μ / 2) • ||w - w^t||^2
    The proximal term (μ = 0.01) mathematically penalizes local updates for deviating from the global consensus wt.
  • Local Differential Privacy (LDP):
    • L2 Gradient Clipping: C = 1.0
    • Gaussian Perturbation: σ = 0.001
    • Guarantees (ε, δ)-Differential Privacy with ε ≤ 4.0.
